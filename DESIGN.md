## Product Context

Multica 本地版一键部署包 is a command-line-first installer and maintenance kit for bringing a private Multica server online across a LAN or NetBird overlay.

## Overview

The visual posture is monochrome Macintosh CRT anime: a recognisable character signal framed by readable diagnostic surfaces. The mascot is a status companion, never a substitute for deployment health. It appears in documentation, empty states, and successful setup acknowledgement only.

## Colors

- CRT ink: `#2E382D` for interface structure and character outlines.
- CRT phosphor: `#DEE4E0` for the pale display field.
- The mascot remains deliberately near-monochrome; no gradients, neon, or status color is embedded in the image.

## Typography

Documentation remains system-sans and code-first. The mascot contains no embedded text, so it survives localization and small sizes. Alt text carries the state meaning.

## Layout

Use the asset at 160–240 px square beside a success summary or a setup/connection explanation. Keep 16 px minimum breathing room. Never let it push command snippets below the fold.

## Components

- **Alice**: an original adult-coded cat-eared 2D anime terminal companion, framed by a Macintosh-style diagnostic interface.
- **Still fallback**: the resting frame, displayed whenever reduced motion is preferred or GIF playback is disabled.
- **Animated loop**: a three-second idle orbit plus one blink; it conveys availability, not urgency.

## Do's and Don'ts

Do use a clear silhouette, restrained black-and-white CRT contrast, a grounded posture, meaningful alt text, and a still PNG.

Do not use eroticized styling, school-uniform cues, text baked into the image, product logos, or a looping motion that reads as a loading spinner or an alarm.

## Source Decisions

- Adopted: requirements-only direction grounded in a private deployment tool and NetBird overlay workflow.
- Rejected: real-world tactical/corporate operator styling, school-uniform clichés, and decorative animation detached from a status or setup context.
